## **Brief Overview**
Auto Shutdown automatically shuts down your Minecraft server after a set period of time when no players are online. You can also configure commands to execute before the server shuts down.

## **Commands**
- `/autoshutdownreload` — Reload the plugin's config

## **Permissions**
| Permission | Description | Who has it by default |
|---|---|---|
| `autoshutdown.reload` | Allows use of /autoshutdownreload | Operators only |

## **Minecraft Version And Server Software**
This plugin was built for all Minecraft versions between 26.3 and 1.9.4 running on Bukkit, Spigot and Paper and Purpur. It may or may not work on other server softwares or versions. It should work on forks of Paper such as Purpur and Pufferfish, though it has not been tested on them.
